# CLAUDE.md — правила работы над DiskApp

Файл читается в начале каждой сессии. Он намеренно короткий: подробности в [PLAN.md](PLAN.md) и `docs/`.

## Что это

DiskApp — приложение в системном трее для быстрой работы с файлами: поиск, открытие, добавление, сохранение, разбор «общего склада» по «профильным складам», резервные копии. Стек: .NET 10, Avalonia 12 + FluentAvaloniaUI 3 (стиль Windows 11), ASP.NET Core Minimal API + SignalR внутри процесса, SQLite (Dapper, FTS5). Описание продукта — [README.md](README.md), устройство — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Как идёт работа

1. Открыть PLAN.md: «Текущая позиция» (раздел 1) и «Открытые вопросы» (раздел 3).
2. Взять первый незакрытый подэтап текущего этапа. Через этапы не перескакивать; исключения — задачи «(опц.)» и исправление дефектов.
3. Для нетривиального подэтапа — короткий план на 3–7 пунктов и явные допущения. Затем код → тесты → Definition of Done (PLAN.md, раздел 1).
4. Обновить PLAN.md: чекбоксы, статус этапа, «Текущая позиция», журнал изменений плана.
5. Отчитаться кратко: что сделано, что дальше, что требует решения пользователя.

## Правила

- Язык документов и общения — русский. Идентификаторы в коде, имена файлов кода и коммиты — английский.
- Решения из PLAN.md (раздел 2) не менять молча: только запись в журнал плана и ADR в `docs/ADR/`.
- Бюджеты производительности (PLAN.md, раздел 8) не ослаблять ради функции: функция уходит за флаг или откладывается.
- Файлы пользователя удаляются только в корзину. Деструктивные операции над данными — только по явному запросу.
- Коммиты в формате Conventional Commits с областью: `feat(index): …`, `fix(search): …`, `docs(plan): …`. Один подэтап — 1–3 коммита.
- Личные данные пользователя (`git user.name`, `user.email`, пароли, токены) не задавать и не угадывать.
- Новые зависимости — только из списка версий в PLAN.md (этап 0.3) или с пометкой в журнале плана.

## Команды

```powershell
dotnet build
dotnet test
dotnet format --verify-no-changes
dotnet run --project src/DiskApp.Desktop
```

Если `dotnet` или `git` не находятся в текущем терминале (PATH не обновился после установки), в начале команды обновить его:

```powershell
$env:Path = [Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [Environment]::GetEnvironmentVariable("Path","User")
```
