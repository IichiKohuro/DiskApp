# Чеклист ручной проверки

Прогоняется после UI-работ соответствующего этапа (Definition of Done, пункт 3) и целиком — перед релизом (этап 10.5). Пункты добавляются по мере реализации; незаполненные разделы — каркас.

Как отмечать: при проверке копировать нужный раздел в заметку с датой, версией сборки и конфигурацией машины, отмечать ✅ / ❌ и ссылку на дефект.

## Общее (каждая проверка)

- [ ] Сборка Release, свежая установка или чистая папка данных (`%LocalAppData%\DiskApp` переименована).
- [ ] Светлая и тёмная тема системы, масштаб 100 % и 150 %.
- [ ] Логи без ошибок уровня Error после сценария.

## Этап 6 — Трей, окна, стиль Windows 11

- [ ] Приложение стартует свёрнутым в трей; иконка видна, подсказка показывает состояние.
- [ ] Меню трея: все пункты работают; выход с подтверждением при активных операциях.
- [ ] Второй запуск не создаёт второго экземпляра; аргументы `--show`, `--search`, `--add` доходят до первого.
- [ ] Хоткей открывает и скрывает окно быстрого поиска; конфликт хоткея показывает понятное сообщение.
- [ ] Автозапуск включается и выключается, состояние отражается в настройках.
- [ ] Mica на главном окне, Acrylic на popup; при отключённой прозрачности — сплошной фон без артефактов.
- [ ] Скруглённые углы у popup; тень; позиция на мониторе с курсором; несколько мониторов с разным DPI.
- [ ] Главное окно запоминает размер и позицию, не уезжает за границы экрана.
- [ ] Подсказка и значок трея меняются: «запускается…» → «индекс актуален»; при сканировании — синий значок и число записей; пауза — жёлтый; недоступный корень — серый; ошибка — красный. Значок читается на светлой и тёмной панели задач.
- [ ] Пункт «Приостановить индексацию» ставит паузу и меняется на «Возобновить индексацию».
- [ ] Сочетание из `settings.json` (`hotkeys.quickSearch`) применяется без перезапуска после правки настроек через API; неверное сочетание — запасное и пояснение в настройках.
- [ ] Крестик главного окна при `tray.closeToTray = false` выходит из приложения (с вопросом, если идут операции).
- [ ] `DiskApp.exe --add <папка>` добавляет корень и показывает итог в главном окне; `diskapp://search?q=…` открывает поиск с запросом.
- [ ] «Эффекты анимации» Windows выключены → окно поиска и страницы появляются без анимации.

- ✅ Трей через 782–783 мс (Release), сервер готов через ≈ 1,1 с; при старте показывается обычная иконка, значки состояний рисуются позже.
- ✅ Окно поиска после анимации появления отрисовано полностью (снимок PrintWindow); страница настроек: действующее запасное сочетание и пояснение с переносом строки.
- ✅ Пауза и возобновление через API (`/index/pause`, `/index/resume`) возвращают состояние; `--exit` завершает экземпляр с кодом 0.
- ⏳ Не проверено руками: вид значков в трее и подсказки, подтверждение выхода при операциях, автозапуск через переключатель, восстановление положения окна после перезапуска, светлая тема и высокая контрастность, несколько мониторов.

### Прогон 2026-10-10 — прототип на макетных данных (Release, Windows 11, тёмная тема, масштаб 125 %)

- ✅ Главное окно: Mica, собственный заголовок с системными кнопками, `NavigationView` с бейджем «12», `InfoBar`, карточки главной страницы, недавние файлы с иконками по виду.
- ✅ Окно поиска: появляется по `--search`, слой Acrylic рендерится, углы скруглены, подсветка совпадений в акцентном цвете, номера `Ctrl+1…9`, звезда избранного, теги, строка состояния.
- ❌ Хоткей `Ctrl+Alt+Space`: занят другим приложением на машине разработчика (ошибка 1409); показано предупреждение в `InfoBar`, поиск доступен из трея — вопрос 14 в PLAN.md.

- ✅ Второй экземпляр (`--search pdf`) передал аргументы первому и завершился с кодом 0; окно поиска показалось в первом экземпляре.
- ⏳ Не проверено руками: меню и щелчок по трею, светлая тема и переключение темы в настройках, `Esc` и потеря фокуса, несколько мониторов, масштаб 100 %.

## Этап 7 — Быстрый поиск

- [ ] Три буквы → результаты ≤ 100 мс; подсветка совпадений; пустой запрос показывает недавние и избранные.
- [ ] Все клавиши из таблицы README работают; `Esc` сначала очищает, затем закрывает.
- [ ] Открыть, показать в Проводнике, открыть с помощью, свойства, копировать путь и файл, в корзину, переименовать.
- [ ] Перетаскивание результата в Проводник, браузер и мессенджер.
- [ ] Иконки типов и миниатюры изображений; файлы OneDrive «по запросу» не скачиваются.
- [ ] После открытия файла он поднимается в выдаче (frecency).

## Этап 8 — Главное окно, операции, «добавить» и «сохранить»

- [ ] Обзор: дерево, список и плитка, сортировка, адресная строка, навигация клавишами как в Проводнике.
- [ ] Копирование, перемещение, переименование, создание, удаление в корзину — с прогрессом и отменой.
- [ ] Конфликты: заменить, пропустить, оставить оба, применить ко всем.
- [ ] `Ctrl+Z` после переименования и перемещения.
- [ ] Drag & drop в приложение и из приложения; `Ctrl+X/C/V` с системным буфером.
- [ ] «Отправить → DiskApp» и контекстное меню Проводника добавляют файлы.
- [ ] `Ctrl+Shift+V`: текст и изображение из буфера сохраняются в файл в выбранную папку.
- [ ] Quick Switch: диалог «Сохранить как» в Блокноте и Word переходит в выбранную папку (если функция включена).

## Этап 9 — Настройки, локализация, онбординг, доступность

- [ ] Каждая настройка применяется без перезапуска или честно просит перезапуск.
- [ ] Переключение RU ↔ EN на лету, нет непереведённых строк.
- [ ] Онбординг проходит за минуту; можно пропустить и вернуться.
- [ ] Экранный диктор озвучивает элементы; навигация только с клавиатуры возможна везде.
- [ ] Высокая контрастность читаема; «уменьшить движение» отключает анимации.
- [ ] Диагностический архив собирается и не содержит секретов.

## Этап 11 — Установка и обновление

- [ ] Установка на чистой VM Windows 11 и Windows 10; ярлыки; автозапуск по выбору.
- [ ] Обновление с предыдущей версии сохраняет данные и настройки.
- [ ] Удаление с вопросом о данных; после удаления нет следов в автозапуске и реестре интеграций.

## Этап 16 — Резервное копирование

- [ ] Копия по кнопке и по расписанию; индексация и поиск не останавливаются.
- [ ] Восстановление «всё / настройки / метаданные / индекс» возвращает ровно то, что было.
- [ ] Повреждённый архив отклоняется; страховочная копия создаётся перед восстановлением.

## Этап 17 — Разбор входящих

- [ ] Новый файл в «Загрузках» попадает в очередь только после завершения загрузки; `.crdownload` игнорируется.
- [ ] Сессия: номера складов закреплены, рекомендуемый подсвечен, одна клавиша — следующий файл.
- [ ] `T` находит любую папку, `N` создаёт подпапку в складе, `Ctrl+W` делает папку складом, `Ctrl+R` создаёт правило.
- [ ] Пакетная обработка похожих файлов; отмена любого решения из журнала.
- [ ] Уведомления по расписанию и по порогу; «не беспокоить» работает.
- [ ] Каскад: файл из «Документов» уходит на «Счета» во вложенной сессии.
