# Чеклист ручной проверки

Прогоняется после UI-работ соответствующего этапа (Definition of Done, пункт 3) и целиком — перед релизом (этап 10.5). Пункты добавляются по мере реализации; незаполненные разделы — каркас.

Как отмечать: при проверке копировать нужный раздел в заметку с датой, версией сборки и конфигурацией машины, отмечать ✅ / ❌ и ссылку на дефект.

## Общее (каждая проверка)

- [ ] Логи без ошибок уровня Error после сценария.

## Этап 7 — Быстрый поиск

- [ ] Три буквы → результаты ≤ 100 мс; подсветка совпадений; пустой запрос показывает секции «Недавно открытые», «Закреплённые», «Недавно изменённые» без повторов.
- [ ] Все клавиши из справки `?` работают; `Esc` сначала закрывает панель действия, затем очищает запрос, затем закрывает окно.
- [ ] Открыть, показать в Проводнике (`Ctrl+Enter`), открыть с помощью (`Shift+Enter`), свойства (`Alt+Enter`), от имени администратора (`Ctrl+Shift+Enter`), копировать файл (`Ctrl+C`) и путь (`Ctrl+Shift+C`), закрепить (`Ctrl+P`), переименовать (`F2`), в корзину (`Del` с подтверждением; файл есть в корзине Windows).
- [ ] `Del` с курсором в середине запроса удаляет символ, а не файл; `Ctrl+C` с выделенным текстом копирует текст.
- [ ] Контекстное меню по правой кнопке, `Tab` и `Shift+F10`; подписи клавиш совпадают с действиями; после закрытия меню фокус в поле.
- [ ] Перетаскивание результата в Проводник (копия; с `Shift` — перенос), браузер (загрузка файла) и мессенджер (вложение).
- [ ] Файлы из Проводника на папку в результатах (страница «Поиск» главного окна) копируются туда; одинаковые имена — обе копии.
- [ ] Иконки типов, свои иконки программ и ярлыков, миниатюры изображений и видео; файлы OneDrive «по запросу» не скачиваются (значок облака, без миниатюры).
- [ ] Чипы вида, даты и корней меняют запрос и подсвечиваются, если фильтр набран руками; `Ctrl+F` прячет чипы.
- [ ] `ext:p` → подсказки расширений, `Tab` дополняет; история при пустом поле, удаление «×» и «Очистить».
- [ ] После открытия файла он поднимается в выдаче (frecency); запрос, из которого открыли, появляется в истории.
- [ ] Светлая тема: заглушки иконок, чипы, панель действия и уведомления читаются.

## Этап 8 — Главное окно, операции, «добавить» и «сохранить»

- [ ] Обзор: дерево, список и плитка, сортировка, адресная строка, навигация клавишами как в Проводнике.
- [ ] Копирование, перемещение, переименование, создание, удаление в корзину — с прогрессом и отменой.
- [ ] Конфликты: заменить, пропустить, оставить оба, применить ко всем.
- [ ] `Ctrl+Z` после переименования и перемещения.
- [ ] Drag & drop в приложение и из приложения; `Ctrl+X/C/V` с системным буфером.
- [ ] «Отправить → DiskApp» и контекстное меню Проводника добавляют файлы.
- [ ] `Ctrl+Shift+V`: текст и изображение из буфера сохраняются в файл в выбранную папку.
- [ ] Quick Switch (включить в настройках → «Интеграция с Проводником»): в диалоге «Сохранить как» Блокнота, Word, браузера и VS Code `Ctrl+Alt+G` открывает быстрый поиск с `type:folder`; `Enter` на папке переводит диалог в неё, на файле — в его папку; имя файла в диалоге остаётся прежним.
- [ ] Quick Switch: `Esc` в режиме выбора закрывает поиск и возвращает в диалог; сочетание вне диалога показывает подсказку «Диалог сохранения не найден»; обычный `Ctrl+Alt+D` после этого открывает поиск без режима выбора.
- [ ] Quick Switch: если сочетание занято другой программой, переключатель не включается и показывает причину; после выключения сочетание освобождается.
- [ ] `Ctrl+D` закрепляет и открепляет файл в быстром поиске, на странице «Поиск» и в «Обзоре» (несколько выбранных — все сразу); звезда в строке и список «Избранное» обновляются.
- [ ] `Ctrl+T` открывает диалог тегов; у нескольких файлов общий тег отмечен, тег части файлов — третьим состоянием и не меняется без переключения; новый тег получает цвет и сразу отмечается; `Enter` в поле нового тега не закрывает диалог.
- [ ] Чипы тегов с цветной точкой видны в строках быстрого поиска, «Обзора», коллекций и в карточке файла; читаются в светлой и тёмной темах.
- [ ] «Теги»: создать, переименовать, сменить цвет, удалить (с подтверждением; файлы остаются); справа — файлы выбранного тега, `Enter` открывает.
- [ ] «Коллекции»: избранное первым; новая коллекция и сохранённый запрос; файлы из Проводника, брошенные на коллекцию слева или на список справа, добавляются; `Alt+↑/↓` меняет порядок; `Del` убирает запись, файл остаётся.
- [ ] «Коллекции»: «Список» → копировать пути, сохранить в `.txt`, загрузить из `.txt` в другую коллекцию; сохранённый запрос сам подхватывает новый подходящий файл в течение 15 секунд.

- [ ] «Поиск»: нечёткий поиск выключен — «reprot» ничего не находит; подборка при пустом запросе выключена — окно поиска пустое до ввода; «Очистить…» удаляет историю.

- [ ] «О программе»: версия, ссылки на репозиторий, релизы и issues открываются в браузере, список сторонних компонентов.

- [ ] Язык: «Внешний вид» → «Язык» → English — меню навигации, страницы, меню трея, окно поиска, диалоги и уведомления сразу на английском; числа «128,412», даты «5 minutes ago», размеры «1.5 KB»; обратно на русский — так же без перезапуска. Английские подписи не обрезаются и не вылезают за кнопки.

- [ ] Переключение RU ↔ EN на лету, нет непереведённых строк.
- [ ] Онбординг проходит за минуту; можно пропустить и вернуться.
- [ ] Чистая портативная копия: мастер поверх главного окна; «Документы», «Рабочий стол», «Загрузки» отмечены; «Добавить папку…» добавляет свою; «Далее» с первого шага начинает индексацию, на последнем шаге растёт счётчик; «Попробовать» и «Открыть быстрый поиск» открывают окно поиска; выключенный автозапуск не пишет ничего в `HKCU\…\Run`; язык English переключает мастер сразу.
