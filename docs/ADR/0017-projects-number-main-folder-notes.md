# ADR-0017: Проекты — свой номер, одна основная рабочая папка, заметки проекта, страница «Проекты»

**Статус:** Принято · **Дата:** 2026-10-17 · **Связано с:** PLAN.md решение 28, вопрос 20, этап 24; ADR-0012 (рабочие папки), ADR-0014 (заметки)

## Контекст

Видение (дополнение 2026-10-12): проект объединяет рабочую папку, заметки и позже напоминания; у проекта номер и узнаваемая иконка — квадрат со скруглёнными углами, цветной фон и номер. Решение 28 оставило открытыми три вопроса (вопрос 20). Ответ пользователя 2026-10-17: у проекта **одна основная папка и много подпапок**; номер — **свой**; список — **отдельная страница «Проекты»**.

## Решение

1. **Модель.** Проект — номер, название, цвет, основная рабочая папка. Номер свой (номер договора «417», «10S-417»), 1–20 символов, уникален без учёта регистра и «ё»; DiskApp номер не придумывает, но при выборе папки подставляет её имя, если номер ещё пуст и имя помещается. Название — до 200 символов, может быть пустым. Цвет — `#RRGGBB` из палитры или свой; без цвета — цвет по номеру из палитры (один и тот же номер — один цвет).
2. **Папка.** Одна основная папка по полному пути; подпапки принадлежат проекту по вложенности, отдельной привязки не нужно. Путь хранится строкой, как у авто-тегов папок (ADR-0012): переживает удаление записи индекса и пересборку, следует за переименованием и переносом папки (наблюдатель и операции DiskApp — через `SortingFolderTracker`). Папка не обязана быть рабочей папкой «Разбора», но выбирается в первую очередь из них.
3. **Заметки.** Колонка `notes.project_id` (миграция V007, `ON DELETE SET NULL`): заметка привязана к одному проекту или ни к одному; привязка — в самой заметке, фильтр заметок по проекту. Удаление проекта не трогает ни папку, ни заметки — заметки остаются без проекта.
4. **Порядок.** Список проектов — по номеру «естественно»: числа внутри номера сравниваются как числа («2» раньше «10», «417» после «99»), без учёта регистра.
5. **Интерфейс.** Отдельная страница «Проекты» в навигации: список с иконками и карточка проекта (номер, название, цвет, папка — «Открыть» на «Обзоре», заметки проекта — «Новая заметка»). Иконка проекта — общий элемент `ProjectBadge`: номер любой длины помещается (уменьшение шрифта, затем перенос), цвет текста — по яркости фона, при высокой контрастности — системные цвета с рамкой. Иконка видна в списке проектов, на чипе рабочей папки на «Разборе» (папка проекта или её подпапка) и у заметок проекта.
6. **API.** `GET/POST /api/v1/projects`, `GET/PUT/DELETE /api/v1/projects/{id}`; занятый номер — 409 `project.duplicate`; `GET /api/v1/notes?projectId=`; несуществующий проект заметки — 400.

## Последствия

- Проект узнаётся по номеру и цвету в трёх местах интерфейса; путь к папке не теряется при переименовании.
- Файлы проекта — это файлы его папки: поиск по проекту — `in:` по папке, отдельного индекса нет.
- Несколько несвязанных папок у проекта не поддерживаются; если понадобится — таблица `project_folders` новой миграцией без смены API списка.
- Напоминания проекта — с этапом 21.4 «Свои напоминания».

## Альтернативы

- **Несколько папок на проект** (предложенное допущение вопроса 20) — отклонено ответом пользователя: одна основная папка, остальное — подпапки.
- **Номер по порядку** — отклонено: пользователь узнаёт работу по своему номеру.
- **Проект как раздел «Разбора»** — отклонено: проект шире разбора (заметки, позже напоминания); отдельная страница.
- **Проект — подпапка рабочей папки без своей таблицы** (решение 28) — нет места для номера, цвета и заметок.

## Проверка

- Тесты репозитория (уникальность номера, переименование папки, счётчик заметок), API (порядок, 409, проверка полей, фильтр заметок, удаление проекта), отслеживание переименования папки на диске, иконки (номер любой длины помещается, цвет текста читается), страницы «Проекты», привязки заметки.
- Ручная проверка иконки в светлой, тёмной теме и при высокой контрастности — QA_CHECKLIST.
