# Замечания из ежедневного использования

Сюда попадает всё, что замечено при dogfooding (с версии v0.3): неудобства, ошибки, идеи. Раз в неделю топ-5 по приоритету переносится в ближайший подэтап PLAN.md (раздел 6, «Dogfooding»).

Приоритет: **P1** — мешает пользоваться каждый день; **P2** — раздражает, есть обход; **P3** — идея или мелочь.
Статус: **новое** → **в плане (этап N.M)** → **сделано (версия)** / **отклонено (почему)**.

## Как записывать

- Одна строка — одно наблюдение, без обобщений вроде «всё медленно»: что делал, что ожидал, что получил.
- Если воспроизводится — шаги и, по возможности, файл из `logs\` с меткой времени.
- Идеи, выходящие за рамки плана, помечать P3 и обсуждать перед переносом в план.
